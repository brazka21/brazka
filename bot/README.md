# BRAZKA Mini App Bot

Небольшой бот без внешних библиотек. Он:

- показывает кнопку `🛒 Открыть магазин` после `/start`;
- открывает `https://brazka.shop/app/` внутри Telegram;
- принимает `Telegram.WebApp.sendData()`;
- отправляет оформленную заявку владельцу магазина.

## Настройка на Windows

1. Скопируйте `.env.example` в файл `.env`.
2. Вставьте токен от BotFather в `BRAZKA_BOT_TOKEN`.
3. Пока оставьте `BRAZKA_ADMIN_CHAT_ID` пустым.
4. Запустите `start_bot.bat`.
5. Отправьте боту команду `/id`.
6. Скопируйте полученный ID в `BRAZKA_ADMIN_CHAT_ID` внутри `.env`.
7. Перезапустите `start_bot.bat`.

Пример `.env`:

```env
BRAZKA_BOT_TOKEN=1234567890:REAL_TOKEN
BRAZKA_ADMIN_CHAT_ID=123456789
BRAZKA_WEBAPP_URL=https://brazka.shop/app/
```

## Прокси HAPP

Если бот не может подключиться к Telegram, добавьте в `.env`:

```env
HTTPS_PROXY=http://127.0.0.1:10809
HTTP_PROXY=http://127.0.0.1:10809
```

Перед запуском HAPP должен быть включён и подключён.

## Проверка заявки

1. Отправьте боту `/start`.
2. Нажмите большую кнопку `🛒 Открыть магазин` под полем ввода.
3. Заполните Mini App и нажмите `Отправить заявку`.
4. Бот должен прислать владельцу карточку заявки.

## Важно про кнопку меню

`Telegram.WebApp.sendData()` используется при запуске Mini App через кнопку `web_app` в клавиатуре бота. Поэтому для проверки реальной отправки заявки открывайте магазин через большую кнопку, которую бот показывает после `/start`.

Кнопку меню, настроенную в BotFather, можно оставить для просмотра интерфейса. Универсальную отправку заявок из кнопки меню позже можно подключить через отдельный HTTPS API.

## Безопасность

- файл `.env` добавлен в `.gitignore`;
- настоящий токен нельзя отправлять в чат, коммитить или публиковать;
- при утечке токена его нужно сразу перевыпустить через BotFather.
